# 项目意图

本文描述产品意图；实现情况和验证范围见 [架构](architecture.md)。

## 目标

Bitori 面向在本地软件工作区中与模型协作的用户：通过对话理解和修改项目，查看工具调用，在执行副作用前按权限规则作出决定，并在本地保留会话。跨平台终端和 Linux 桌面端是当前入口；适配不同模型协议、限制工作区文件访问和提供可排查的运行记录是主要约束。

## 非目标与验收方向

多模态、会话导入和自动断点续跑已由用户明确纳入本轮产品建设，功能实现已接入、正在完成集成验收。首版范围是本地图片（桌面选择/粘贴、终端路径）、Bitori 版本化 JSON 会话导入/导出，以及基于持久化检查点的续跑；已完成工具不直接重放，不确定写入或命令先由用户确认。云同步已取消并保持不支持，见 [决策记录](decisions/0001-cloud-sync-out-of-scope.md)。验收时应检查工作区理解与修改、工具调用展示、副作用审批和会话保存，并分别记录平台与真实模型的验证结果。
