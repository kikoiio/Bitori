# [s10] Skill 系统

> 本文是 s10 完成时点的实现快照，后续阶段可能已替换或扩展其中实现；当前架构以最新阶段文档与源码为准。

## 目标

把可复用 SOP 变成 Markdown 技能包：启动时轻量目录，激活后完整指令进入环境上下文，后续可挂 LoadSkill 工具与 `/skill` 管理命令。

## 设计

- `SkillMeta` 记录 name、description、allowedTools、mode、forkContext、model。
- `SkillLoader` 扫描 `~/.bitori/skills` 与 `.bitori/skills`；项目级同名覆盖。支持单文件与目录型 `SKILL.md`，`getFresh` 执行前重读。
- `ActiveSkills` 保存激活顺序并渲染 `## Active Skills` 段；`SkillExecutor.executeInline` 替换 `$ARGUMENTS` 后激活。
- fork 模式的独立 Agent 会话将在 SubAgent 阶段复用 AgentRunner 派生执行，当前先保留元数据与执行入口。

## 与课程差异

课程在本章同时接入 LoadSkill 工具、InstallSkill、TUI `/skill` 管理和 fork 临时 Agent。Bitori 先稳定解析、加载、热更新与激活状态；工具接入依赖现有 ToolRegistry 生命周期，放到与 Hook/SubAgent 一起集成，避免一次性改动过大。
