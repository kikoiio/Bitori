# 决策：Linux 桌面端

状态：Linux 初版已实现，尚未发布。目标是让用户在 Linux 图形环境中使用现有聊天、会话和工具审批能力，保留终端入口及现有配置和数据。

采用 Electron 管理窗口，使用独立渲染进程展示界面；业务控制器、配置、存储和工具执行留在主进程。渲染进程开启沙箱和上下文隔离，通过 preload 暴露受限操作；消息、工具参数和模型输出以文本渲染。工作区切换前要求用户确认信任，切换后重新加载项目配置和服务。

选择这一方案是为了复用已有 Node.js 和 TypeScript 核心以及 SQLite 工作线程。代价是发行包和运行时资源占用高于轻量原生壳；目前没有承诺 Windows 或 macOS 桌面发行包。

完成标准：配置有效时能启动桌面窗口、流式聊天、切换和恢复会话、审批或拒绝副作用调用并停止任务；Linux 安装包可启动。Linux desktop 工作流已验证开发入口的聊天、批准和拒绝工具调用、取消、会话切换，以及解包后的发行程序启动；AppImage 和 deb 已构建。真实模型、安装流程和发行版兼容性需要另行验收。
