# 第 01 课：项目与全屏聊天客户端

- 前置：无。
- 结果：Bitori 能在 Windows Terminal 中全屏运行，用三种模型协议完成流式对话，并持久化多会话。
- 预计：8-10 小时。
- 环境：Windows 10/11、Node 24 LTS、Windows Terminal + PowerShell；测试真实协议时需要一个 Anthropic、一个 OpenAI Responses 和一个 OpenAI Chat 兼容 profile。

## 1. 为什么学这一课

Bitori 的后续能力都建立在一个稳定客户端上：配置解析、流式模型调用、终端渲染、会话持久化和安全退出。本课先把这些基础打通。完成后再进入工具系统，就不会把协议、界面和存储问题混在一起。

## 2. 能力规格

- 运行 `Bitori` 进入全屏 TUI，界面包含消息区、输入区和状态区。
- 固定读取 `%USERPROFILE%\.bitori\config.yaml` 与同目录 `.env`，不搜索其他配置位置。
- 支持 Anthropic Messages、OpenAI Responses、OpenAI Chat Completions；输出文本流、thinking、usage 和错误事件统一为 `StreamEvent`。
- 支持多 profile 选择、`--profile` 参数和 `--help`。
- 多会话创建、切换、恢复；SQLite 保存消息，流式内容按 checkpoint 落盘。
- 空闲 Ctrl+C 退出并恢复终端；生成中 Ctrl+C 取消但保留已生成内容。

## 3. 代码走读

按一次消息的路径阅读：

1. `src/bin/bitori.ts`：只解析参数并调用 bootstrap。
2. `src/cli/args.ts`、`src/cli/bootstrap.ts`：参数校验、Node/Windows 检查和对象组装。
3. `src/config/`：YAML/.env 加载、schema 校验、类型和密钥展开。
4. `src/providers/`：三个协议适配器与统一 `LLMClient` 接口。
5. `src/chat/`：上下文组装、状态机与控制器。
6. `src/storage/`：Worker、迁移、Repository 与 SQLite 写入。
7. `src/tui/`、`src/terminal/`：React + Ink 界面与终端恢复。
8. `tests/unit/`、`tests/integration/`：从测试反推每层契约。

初学者可先读 `Project_Guide/s01.md`，其中包含 TypeScript 语法提示和完整调用图。

## 4. 实现任务

1. 建立 ESM package：Node 24 约束、`Bitori` bin、check 脚本。检查项为 `node dist/bin/bitori.js --help` 显示用法。
2. 实现配置加载与校验。检查项为非法 YAML、非法协议、缺密钥均有可定位错误。
3. 实现三 Provider 与统一流事件。检查项为三个协议的单测覆盖 text、thinking、usage、completed、error。
4. 实现 SQLite 存储与迁移。检查项为消息、会话、checkpoint 和终态测试通过。
5. 实现 TUI 与终端生命周期。检查项为消息区、输入区、状态区、会话列表和取消行为可见。
6. 完成 README 与 checklist。检查项为安装、配置、快捷键和当前边界真实准确。

## 5. 检查点

### 自动验证

```powershell
npm run check
node dist/bin/bitori.js --help
```

### 人工验收

在 Windows Terminal 分别启动单 profile、多 profile 和 `Bitori --profile <name>`；验证三协议真实对话、流式输出、取消、退出恢复和重启后的会话恢复。结果记录到本课 `checklist.md`。

## 6. 常见卡点

- SDK 事件结构与 Mock 不一致：先固定一个最小真实响应样本，再写适配测试。
- 终端退出后乱码：确认所有退出路径都经过统一的 terminal shutdown，不直接 `process.exit`。
- Windows 大小写不敏感路径：路径比较使用大小写不ensitive API，不用字符串相等。
- 数据库跨线程访问：所有 SQLite 操作保持在 worker 内。

## 7. 延伸与边界

本课刻意不实现工具调用、命令执行、系统提示和权限。纯对话客户端的边界让学生集中处理协议、状态与持久化；工具系统在第 02 课引入。
