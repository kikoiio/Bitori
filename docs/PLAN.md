# Bitori harness RSI 实施计划

## 维护规则

- 本文件只保留尚未完成或尚未通过真实验收的工作，不记录已完成实现的历史。
- 已实现行为和维护方式写入[评测说明](../evaluation/README.md)、[架构](architecture.md)与测试，不在此重复。
- 每项通过验收后立即从本文件删除；全部完成后删除本文件及[文档索引](README.md)中的计划链接。
- 本文件描述待验证能力，不代表功能已经可用。

## 目标与边界

RSI 指持续改进本项目的 coding-agent harness，不训练底层模型。改动必须在独立分支生成，可信 verifier 通过且人工审查完成才允许合并；已合入版本才成为下一轮基线。自动合并、无人值守循环、正式 300 题测试和修改评分门槛均不在范围内。代码路径、实验命令、预算和证据白名单见[评测说明](../evaluation/README.md)。

## 1. 真实容器隔离与预算验收

离线测试已覆盖假服务、补丁越权、stale SHA、预算与恢复；以下必须用真实 Docker 复核，不能用单元测试替代。

- [ ] 在临时 Docker 环境确认候选容器读不到宿主探针、真实密钥、主仓库 `.git`、Docker socket 和 gold/`instance.json`。
- [ ] 确认真实容器只能经可信转发器出网，无法直接访问任意外部地址；转发器拒绝动态上游和跨域重定向。
- [ ] 用假上游验证三协议流式文本、工具调用、错误和用量在真实容器网络中的透传。
- [ ] 验证超时、强制终止和容器清理：终止后证据已收集、本实验容器与内部网络被清理，未遗留可复用凭据。
- [ ] 验证账本在真实请求下按请求/输出上限阻断，缺失 usage 时保守记账，预算耗尽后不再发起新请求。

**验收**：保留真实 Docker 命令输出与证据摘要。未运行就明确标注隔离未验证，且不得启动真实自动候选执行。

## 2. 受控云端单题 smoke

- [ ] 运行前展示供应商、模型、预算、云端服务和上传范围并取得明确授权；当前范围为讯飞第 0 题 baseline 加至多一个候选，不扩展到 23 题。
- [ ] 通过 `.github/workflows/rsi.yml`（仅 dispatch、默认分支代码、完整基线 SHA、确认短语）执行一次真实 smoke，记录运行链接、候选分支/head SHA、产物、诊断、verifier 结论与实际消耗。
- [ ] 合法拒绝、无候选、`iteration_limit`、预算耗尽或链路故障都如实保留终态，不无限重试，不把 smoke 通过说成 harness 能力提升。
- [ ] 核对上传 artifact 不含 gold、真实密钥、原始 thinking、worktree 或构建产物；失败时也保留可解释证据。

**验收**：一次真实运行证明“记录 → 诊断 → 候选分支 → 可信检查 → 独立 verifier → 终态报告”可执行。单题结果不用于宣称泛化或统计显著提升。

## 3. 可信 required check 与分支保护

当前 verifier 只能在本地/CI 生成诊断结论；尚未配置受信任来源的 GitHub 必需检查与目标分支保护，因此不能宣称“未通过 verifier 无法合并”。

- [ ] 决定并实现可信检查的发布来源（受保护 workflow/受信任应用），使其绑定实际候选 head、目标 base、必要的集成 merge SHA 和报告摘要；候选分支自定义的同名 job 或手工 JSON 不能冒充。
- [ ] 在获得明确授权后配置目标分支 ruleset/分支保护：必须通过该可信检查与人工审查，目标分支推进后须重验或经过合并队列；缺失、失败、取消、超时和过期检查一律阻止合并。
- [ ] 用获授权的测试 PR 验证上述检查确实阻止合并；未验证前只能称 verifier 为诊断工具。
- [ ] 推送分支、创建 PR、修改保护规则和实际合并分别取得授权，不绕过管理员或仓库规则。

**验收**：测试 PR 证明未通过、缺失或过期检查无法按正常流程合并；只有对应版本全部必需检查通过且人工审查完成才可合并。

## 4. 合并级与泛化验证

- [ ] 为合并级实验提供独立 reviewed 配置（至少 2 个配对任务、冻结目标与回归门槛），不能复用单题 smoke。
- [ ] 冻结候选后才单独授权保留验证（dev 16–22）；结果只交人工审查，不反复反馈给生成器调参。若据此继续改进，承认该集合不再是保留验证。
- [ ] 首个通过合并级验证的 harness 在人工审查并实际合入后，才成为下一轮实验基线；未合入候选不得改写控制面或基线。
- [ ] 报告同时呈现正式解题率、可靠性、token、耗时、样本量和未验证项；证据不足输出 `inconclusive`，不宣称统计显著提升。

**验收**：至少一次合并级配对验证与保留题审查记录；合并动作本身仍需单独授权。

## 本轮明确不做

自动合入、无人值守无限 RSI、训练模型权重、自动修改评测门槛、全量 300 题正式测试、基于单次 smoke 宣称泛化、把未提交用户配置或 dirty 工作区夹带进评测快照。
