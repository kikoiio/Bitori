# [s14] Agent Teams

## 目标

把一次性 SubAgent 升级为长期协作团队：稳定成员花名册、成员邮箱、团队配置持久化与可观测进度。

## 设计

- `TeamManager` 按 sanitized 名称在团队主目录下建目录，`team.json` 保存团队与成员状态。
- `FileMailbox` 每成员一个 JSONL 文件，`wx` 文件锁保护并发追加；read 游标独立保存，新实例可继续消费。
- `progress.ts` 记录工具调用与 token，最近 5 条活动用于状态栏和 spinner。
- 运行中成员阻止团队删除，`force` 才允许强制清理。

## 关键文件

- `src/teams/file-mailbox.ts`
- `src/teams/team.ts`
- `src/teams/progress.ts`
- `tests/unit/teams/teams.test.ts`

## 与课程差异

课程还包含 tmux/iTerm2/in-process 后端、5 个团队工具和 Coordinator Mode。Bitori 已有 Orca/终端生态，本阶段先交付团队域模型与通信基础；后端检测与工具注册将在真实 AgentRunner 集成阶段按现有 ToolRegistry/权限链路接入。
