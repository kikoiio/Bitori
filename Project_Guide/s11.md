# [s11] Hook 生命周期系统

## 目标

提供事件 + 条件 + 动作的自动化规则引擎，支持命令执行、提示注入、HTTP 通知与工具前拦截。

## 设计

- `src/hooks/types.ts` 定义 15 个生命周期事件与 Hook 配置。
- `src/hooks/engine.ts` 实现条件解析（==/!=/=~/~=，&&/|| 二选一）、变量展开、command/prompt/http/agent 四类动作。
- `once` 用运行时 Set；`async` 只后台执行不等待；`pre_tool_use` 禁止 async。
- prompt 输出进入 notifications，消费方 drain 后作为下一轮 system reminder。
- 拦截语义：`reject: true` 时 Hook 输出成为工具拒绝原因，反馈给模型调整策略。

## 关键文件

- `src/hooks/types.ts`
- `src/hooks/engine.ts`
- `tests/unit/hooks/engine.test.ts`

## 与课程差异

课程把 YAML 配置和 Agent 生命周期接线放在同一章。Bitori 的配置加载已有 Zod schema 与项目级合并，HookEngine 已独立可测；生命周期接入将结合现有 AgentRunner/SafetyBatchScheduler 在集成阶段统一完成，避免并行修改调度器引入竞态。
